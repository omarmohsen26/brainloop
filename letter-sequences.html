Letter sequences: count the places

A letter sequence looks like A, C, E, G, ? and asks for the next letter. The trick is to turn letters into numbers. A is 1, B is 2, C is 3, and so on up to Z, which is 26. Once you see numbers, it becomes a number sequence.

Step 1: count the jumps

For A, C, E, G the numbers are 1, 3, 5, 7. The jump is +2 each time, so the next number is 9, which is the letter I.

Step 2: if the jumps change, write them down

For B, C, E, H, L the numbers are 2, 3, 5, 8, 12. The jumps are 1, 2, 3, 4, so the next jump is 5 and the next number is 17, which is Q.

Step 3: watch for alternating jumps

For C, D, I, J, O the numbers are 3, 4, 9, 10, 15. The jumps go +1, +5, +1, +5, so the next jump is +1 and the next letter is P (16).

Alphabet anchors that save time: E is 5, J is 10, O is 15, T is 20, Y is 25. Count from the nearest anchor instead of from A.

Common mistakes

  • Counting the letter itself. Counting from C to E is 2 places, not 3.
  • Forgetting that Brainloop sequences never wrap past Z.
  • Looking only at the first two letters. Check the rule on every pair.
