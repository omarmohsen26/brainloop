Mini sudoku (4 by 4): rules and tips

The rules

Fill the grid with the numbers 1, 2, 3 and 4. Every row must contain each number once. Every column must contain each number once. Each of the four 2 by 2 boxes, marked by the thick lines, must also contain each number once.

Method 1: the only number that fits

Pick an empty cell. Look at its row, its column and its box. Cross off every number you can already see. If only one number is left, that is the answer. In a 4 by 4 grid this alone solves many puzzles.

Method 2: the only cell that fits

Pick a number, for example 3. Look at a row, column or box where 3 is missing. If every empty cell but one already sees a 3 in its row or column, the 3 must go in the last cell.

Method 3: rows that are almost full

A row with three numbers filled in is solved: the missing number is the one you cannot see. Scan for rows, columns and boxes with three numbers first.

Example. A row reads 2, _, 4, 1. The only missing number is 3, so the blank is 3.

No guessing needed

Every Brainloop mini sudoku has exactly one solution, and it is checked by the program before you see it. If you feel stuck, it means a cell has more clues than you have used yet. Go back to Method 1 on a different cell.

Check button

You can use Check as often as you like, but a solve after a wrong check scores half a point instead of one. Try to be sure before you press it.
