Shape math: solve for each symbol

In a shape math puzzle each symbol stands for a number. The same symbol is always the same number. You are given a few equations and asked to work out the last line.

Start with the line that has only one kind of shape

If a line reads ● + ● + ● = 18, then three of the same shape make 18, so ● is 6. That is your first solid fact.

Substitute and move on

If the next line reads ● + ■ = 10, put 6 in for ●: 6 + ■ = 10, so ■ is 4. Keep going until every shape is known.

Hard mode: multiplication

A line like ● × ● = 25 means ● times itself is 25, so ● is 5. Then ● × ■ = 25 gives ■ = 5. Learn the squares (4, 9, 16, 25, 36, 49) to spot these fast.

Example. ● + ● + ● = 15, ● + ■ = 9, ■ + ▲ = 11, ▲ + ● = ?
● = 5. ■ = 4. ▲ = 7. So ▲ + ● = 12.

Check your work

Put your values back into every line. If one line fails, one of your steps is wrong. Fix it before you answer.
