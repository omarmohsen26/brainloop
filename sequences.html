Number sequences: how to find the rule

A number sequence puzzle shows a row of numbers and asks for the next one. Every sequence follows a rule. Your job is to find it. The trick is to check a short list of common rules in a good order.

Step 1: look at the gaps

Subtract each number from the next one. If the gaps are all the same, you have an add-the-same-number rule. Example: 7, 12, 17, 22, 27. The gap is always 5, so the next number is 32.

Step 2: if the gaps change, look at the gaps of the gaps

If the gaps grow by the same amount each time, you have a growing-gap sequence. Example: 3, 5, 8, 12, 17. The gaps are 2, 3, 4, 5, so the next gap is 6 and the answer is 23. Square numbers also behave this way: the gaps between 1, 4, 9, 16 are 3, 5, 7.

Step 3: try multiplying

If the numbers grow very fast, divide each number by the one before it. A constant answer means you have a multiply-by-the-same-number rule. Example: 2, 6, 18, 54, 162. Each is 3 times the one before, so the next is 486. A close cousin is double-then-add: 4, 9, 19, 39, 79. Each number is double the last, plus 1, so the next is 159.

Step 4: check for two patterns at once

If the gaps jump back and forth, the step may alternate. Example: 5, 7, 14, 16, 23. The steps go +2, +7, +2, +7, so the next is 25.

Step 5: check if each number adds up the previous two

Example: 2, 3, 5, 8, 13. Each number is the sum of the two before it, so the next is 21. This is the Fibonacci pattern.

Quick checklist: same gap, growing gap, same multiplier, alternating step, sum of the last two. Almost every sequence in Brainloop is one of these five.

Habits that help

  • Write the gaps down. Do not try to see the answer all at once.
  • Test your rule on every pair in the sequence, not just the first two.
  • When two answers both look right, pick the one that fits the rule on all the numbers.
