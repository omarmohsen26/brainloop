Number grids: read the rule across rows

A number grid is three rows of three numbers. Every row follows the same rule to get its last number from the first two. The last cell of the third row is empty. Find the rule from the complete rows, then apply it.

Test the four common rules

  • Add: first + second = third. Row 4, 7, 11 fits.
  • Subtract: first − second = third. Row 20, 6, 14 fits.
  • Multiply: first × second = third. Row 3, 5, 15 fits.
  • Double plus: twice the first + the second = third. Row 4, 3, 11 fits.

Method

  1. Look at the first row only. Try each rule until one works.
  2. Check that rule on the second row. If it fails, try another one.
  3. Apply the rule to the first two numbers of the third row.
Example. Rows: 9, 6, 15 and 6, 12, 18 and 10, 2, ?. Row one: 9 + 6 = 15. Row two: 6 + 12 = 18. The rule is add. So 10 + 2 = 12.

Tip

If two rules both fit one row (for example 2, 2, 4 fits both add and multiply), use the second row to decide.
