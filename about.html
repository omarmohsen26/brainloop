About Brainloop

Brainloop is a free daily puzzle game. Each day there are five short puzzles: a number sequence, a logic question, an odd-one-out, a mental math sum and a mini sudoku. A set takes about five minutes.

What we care about

  • Short and calm. One set a day. No timers, no pressure.
  • Fair puzzles. Every puzzle is generated by code and checked so that it has one correct answer.
  • Private. No accounts, no tracking, nothing sent off your device.
  • Honest. It is a game. It is not an IQ test and we do not promise it will make you smarter.

How it is built

Brainloop is a progressive web app. It is plain HTML, CSS and JavaScript, with no external libraries, fonts or images from other sites. It works offline once opened and updates itself in the background, without asking you to reinstall.
